# Apple M4 baseline — 2026-08-15

This baseline covers build reproducibility and local idle behavior for current master `256022d3` with dependency bundle `v12`. It does **not** claim a streaming baseline: no controlled Sunshine host, fixed content, or Ethernet endpoint was supplied.

## Environment

- Mac16,12, Apple M4 (10 CPU / 10 GPU cores), 16 GiB, built-in 2560×1664 Retina display
- macOS 26.6.1 (25G76), Xcode 26.6 (17F113), SDK 26.5, Apple Clang 21.0.0
- Qt 6.11.1 official universal package for the universal build
- Battery power at 95%; macOS reported no thermal or performance warning
- `v12` macOS archive: 28,492,950 bytes, SHA-256 `446228fb68d5aef4bb8791f08e5e98e38e6ecffdefac7633902fc463189a0f3c`

## Build results

| Build | Result | Slices | Minimum macOS | Important note |
|---|---|---|---:|---|
| Native Debug | Pass | arm64 | 14.0 | Local Homebrew Qt is arm64-only and built for macOS 26, so this is compile evidence, not a distributable macOS 14 app. |
| Native Release | Pass | arm64 | 14.0 | Same Homebrew Qt limitation. |
| Universal Release | Pass | x86_64, arm64 | 13.0 | Built with the same Qt 6.11.1 universal distribution used by CI. |

The deployed universal bundle contains 105 Mach-O files and every one has both slices. Validation found one forbidden absolute dependency: the unused Qt Mimer SQL plugin links `/usr/local/lib/libmimerapi.dylib`. `macdeployqt` logged this missing file. The local bundle is also unsigned, as expected; signing and notarization were not attempted.

## Repeat idle result

Each run used a 10-second warm-up followed by 30 one-second samples on Moonlight’s computer-list UI.

| Metric | Run 1 | Run 2 | Difference |
|---|---:|---:|---:|
| Mean CPU | 0.710% | 0.637% | 0.073 percentage points |
| Mean resident memory | 155,657,830 B | 155,428,454 B | 0.15% |
| Peak resident memory | 156,106,752 B | 155,795,456 B | 0.20% |

The repeat meets the recorded idle-noise bounds of 0.1 CPU percentage point and 1% memory. It does not establish stream-run repeatability.

## Excluded run and remaining measurements

An initial automation run forced Qt’s `offscreen` platform and aborted during `QGuiApplicationPrivate::createPlatformIntegration()` because that plugin is not bundled. The crash report identifies Python as the parent and the Codex app coalition. The harness now uses the normal Cocoa platform, and both repeat runs exited cleanly.

Startup-to-ready, stream CPU/GPU/energy/memory, decode/render/GPU/present timing, audio depth/underruns, input event-to-send, jitter/loss, and dropped frames remain explicit `null` fields in the JSON. They require the controlled host plus the non-invasive timing counters assigned to Phase 1.
